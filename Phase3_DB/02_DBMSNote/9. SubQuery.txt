1. SubQuery 
    1) 쿼리문 내에 또다른 쿼리문이 있는 형태 
        - 쿼리 안에 또 다른 SELECT문을 괄호()로 감싸 넣은 것 
    2) 서브쿼리는 메인쿼리에 포함되는 관계
    3) ()를 사용해 감싸는 형태 
        - 서브쿼리는 반드시 소괄호로 감사 사용함
        - 서브쿼리는 메인쿼리(주쿼리)를 실행되기 전에 1번만 실행됨 
        - 비교 연산자와 함께 서브쿼리를 사용하는 경우
            - 서브쿼리를 연산자 오른쪽에 기술해야 함 
    4) 서브 쿼리 내부에는 order by는 사용할수 없음 

2. 서브쿼리 종류 (반환값 기준 4가지)
    1) 스칼라 서브쿼리 
        - 단 하나의 값(셀)을 반환
            - 1행 * 1 컬럼
        - 마치 변수처럼 사용됨 
        - 2행 이상 반환 시 에러 상황 
        - 사용 위치 
            - SELECT / WHERE / HAVING
    2) 컬럼 서브쿼리 (다중행) 
        - 값의 목록(리스트)을 반환
        - IN, ANY, ALL 연산자와 함께 사용 
        - 반환: N행 * 1 컬럼 
        - 사용 위치 
            - WHERE (IN/ANY/ALL)   
    3) 행 서브쿼리 
        - 하나의 행(여러 컬럼) 반환
            - (col1, col2) = (서브쿼리)형태  
        - 반환: 1행 * N컬럼 
        - 사용 위치 
            - WHERE (열 비교)        

    4) 테이블 서브쿼리 (인라인 뷰)
        - 결과 전체가 가상 테이블 
        - from 절에서 실제 테이블처럼 사용 
        - 별칭 필수! 없으며 에러! 
        - 반환: N행 * N컬럼
        - 사용 위치
            - FROM 절 (별칭 필수!)

3. 서브쿼리 위치별 사용 
    1) WHERE 절 
        - 조건 필터링에서 가장 많이 사용 
        - 기준값을 동적으로 계산해서 필터링할 때
