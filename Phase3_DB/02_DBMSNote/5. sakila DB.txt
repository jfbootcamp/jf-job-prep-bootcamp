1. sakila DB란 
    1) DVD (Video Retal Store) 대여점 시스템 
    2) MySQL 공식 제공 샘플 데이터베이스 16개 테이블 | 6개 뷰
    3) DVD 대여점 운영 시스템을 모델링 
    4) 목적
        - 실제 비즈니스 관계를 반영한 정규화된 설계 
        - 테이블 간 FK 관계가 다양 (JOIN 연습)
        - 충분한 데이터 양 (약 47,000건 이상)

2. DVD 대여점 핵심 비즈니스 흐름 

3. sakila DB 의미
    1) 가상의 회사, MySQL 팀이 직접 설계하고 데이터를 채워 넣은 것임 
    2) 정합성 보장
        - 외래 키(FK) 제약조건 
            - 모든 테이블 간 관계가 FK로 연결되어 있음 
            - 존재하지 않는 customer_id로 결재를 넣은 것 자체가 불가능 
        - NOT NULL / CHECK 제약조건 
            - 필수 값 누락이나 잘못된 값 방지 
    3) 사전 설계된 데이터 
        - 랜덤이 아니라, 의미 있는 결과가 나오도록 의도적으로 설계된 데이터 
    4) 규모 
        - 테이블            건수
         ------------------------
          고객(customer)   599명
          영화(film)       1,000편

          매장(store)      2개                  store_id    주소
