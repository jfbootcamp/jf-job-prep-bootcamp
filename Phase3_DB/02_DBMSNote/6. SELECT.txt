1. SELECT 
    1) 기본 형식 
        - SELECT [열] FROM [테이블]
          WHERE [열] = [조건절]  

        - SELECT 조회할 컬럼
          FROM 데이터 소스, 테이블 지정, JOIN으로 여러 테이블 연결 
          WHERE 행(ROW) 단위 필터링  

    2) 작성 순서(우리가 쓰는 순서) vs  
        ①②③④⑤⑥⑦⑧⑨
           ① SELECT 컬럼목록            
           ② FROM   테이블명            
           ③ WHERE  조건식
           ④ GROUP BY
           ⑤ HAVING
           ⑥ ORDER BY 정렬컬럼              
           ⑦ LIMIT 건수                  


       실행(처리) 순서    
            ① FROM  -- 테이블 접근 & JOIN 처리            
            ② WHERE -- 행 필터 
            ③ GROUP BY -- 그룹화 
            ④ HAVING -- 그룹 필터링 
            ⑤ SELECT -- 컬럼 선택, 계산, 별칭 생성
            ⑥ ORDER BY 정렬 (SELECT 별칭 참조 가능)
            ⑦ LIMIT 결과 건수 제한 

    3) WHERE 문으로 조건에 맞는 데이터 조회하기 
        - = 연산자로 특정 값 조회 
        - 비교연산자 (<>, !=, <, >, <=, >= ...)
        - 논리연산자 (and, or)
        - BETWEEN
            - 범위에 있으면 데이터를 조회
            - 두 경계값을 포함하여 검색을 수행함           
        - IN 연산자
            - 여러 개의 OR를 간단하게 표시할 수 있음
            - NOT IN 으로 제외 조건도 가능함  

        - ORDER BY (정렬)
            - ASC (오름차순, 기본값)
                - 숫자 : 1, 2, 3, 4, 5....
                - 문자 : A, B, C, ....Z
                - 날짜 : 오랜된 날짜 --> 최근 날짜 
            - DESC (내림차순)
            - 복합 정렬 (여러 컬럼)
                - 순서가 중요! 앞에 있는 컬럼이 우선순위 높음 
                - 예) ORDER BY store_id DESC, first_name ASC 
                    - 먼저 store_id 기준 내림차순 정렬
                    - store_id가 같으면 first_name 기준 오름차순 정렬         

        - LIMIT / OFFSET (페이징 처리)
            - LIMIT 10
                - 앞에서 10개만
            - LIMIT 100, 10
                - 100번째 건너띄고 10개 (게시판 페이지 11)  
            - LIMIT 10 OFFSET 100 
                - (앞과 같은 의미, 더 읽기 좋음)    

        - LIKE 
            - 패턴 매칭 
            - 와일드카드 2가지
                - % (퍼센트)
                    - 0개 이상의 임의 문자 (길이 제한 없음)
                - _ (언더스코어)
                    - 정확히 1개의 임의 문자 (자리수 고정)
            - 예
                패턴            의미                매치 예
               -------------------------------------------------------                    
               LIKE 'A%'     A로 시작하는 모든 것     ANA, ALICE, ASHLEY 
               LIKE '%A'     A로 끝나는 모든 것       DIANA, ROSA, LINDA
               LIKE '%A%'    A가 포함된 모든 것       ANA,  DIANA, KAREN
               LIKE 'A_'     A로 시작하는 2글자       AN, AL (정확히 2글자)
               LIKE 'A__'    A로 시작하는 3글자       ANA, AMY (정확히 3글자)
               LIKE 'A__A'   A로 시작, A로 끝나는 4글자      ANNA (정확히 4글자)

            - NOT LIKE 
                - 패턴에 일치하지 않는 것
                - 예) LIKE 'A%' --> A로 시작하는 것    
                      NOT LIKE 'A%' --> A로 시작하지 않는 것

2. NULL 값
    1) NULL이란 해당 컬럼의 값이 없다는 의미 
        - 해당 컬럼이 NULL 값을 허용하는 경우 
    2) NULL 값을 가지고 있는 컬럼을 검색하려면 is NULL 
    3) NULL이 아닌 값을 가지고 있는 컬럼을 검색하려면 is not NULL            

3. REGEXP
    1) 정규표현식 패턴 매칭
    2) REGEXP 주요 패턴
        - ^ (캐럿)
            - 문자열 시작 
            - 예) REGEXP '^K' --> K로 시작하는 것 
        - $ (달러)
            - 문자열 끝
            - 예) REGEXP 'N$' --> N으로 끝나는 것
        - | (파이프)
            - OR 조건 
            - 예) REGEXP '^K|N$' --> K로 시작 OR  N으로 끝나는 것  
        - [문자집합] 
            - 집합 중 하나 
            - 예) REGEXP 'K[L-N]' --> KL, KM, KN 포함 
        - [^문자집합]
            - 집합 외의 것
            - 예) REGEXP 'K[^L-N]' --> KL, KM, KN 제외한 K+문자 

4. LIKE vs REGEXP 

        구분               LIKE                      REGEXP
      -------------------------------------------------------------------------
      사용 목적            단순 패턴 (시작/끝/포함)     복잡한 패턴 (집합, OR, 위치)
       성능                빠름 (단순 비교)            느림 (정규식 엔진 사용)
       조합 가능            AND / OR와 조합 가능        LIKE와 함께 사용 가능
