0. 리액트 컴포넌트(component)
    1) 화면을 구성하는 최소 단위 
    2) 자신의 상태(state)를 가질수 있으며, 이를 통해 데이터를 관리하고 
       동적인 UI를 구성
    3) 컴포넌트는 독립적으로 작동하고 렌더링되는 앱의 조각

1. 리액트의 데이터 흐름
    1) 각 컴포넌트는 자신만의 상태를 가짐
    2) 데이터의 전달은 프롭스(props) 사용
    3) 탑-다운(Top-down) 방식으로 부모가 자식에게만 전달하는 것이 기본.
    4) 자식이 부모쪽으로 데이터를 전달하고 싶다면 이벤트 사용 

2. 리액트 구성요소
    1) 구역 
        - 로직 구역 (준비 구역)     <----- JS 코드 실행 
            - 상태 선언 (useState)
            - 사이드 이펙트
            - 이벤트 핸들러
            - 조건 계산
            - API 호출 
            - 변수 선언

        - 렌더링 구역 (식탁 구역)  <------ JSX로 화면 그리기 
            - 표현식
            - 조건부 렌더링
            - 리스트 렌더링  

3. JSX란?
    1) 자바스크립트의 확장 문법 (JavaScript XML)
    2) HTML처럼 보이는 코드를 자바스크립트의 안에서 사용할 수 있게 해줌.
    3) 자바스크립트 문법을 기반으로 함 
        - HTML의 class 속성 대신 className을 사용해야 함.
    4) React에서 UI를 효율적으로 만들기 위한 문법 도구임 
    5) HTML과 비슷하지만 실제로는 자바스크립트 코드라는 점이 핵심.
        - html에 class 넣을 땐 className   

4. JSX 문법
    1) 반드시 부모 요소 하나가 감싸는 형태여야 함 
        - <> </>
            - Fragment(프래그먼트)라고 함.
            - 단축 문법임.             
    2) JSX안에서도 자바스크립트 표현식을 사용할수 있음 
        - JSX내부에서 코드를 { }로 감싸주면 됨
        - 유효한 모든 JavaScript 표현식을 넣을 수 있음   

    3) 조건부 렌더링 패턴 
        - if / else + 변수 (return 밖)
        - 삼항연산자 ? : 
        - AND 연산자 (&&)
        - 즉시실행함수(IIFE)
            - (() => {
                return 결과값;    
              })()     

    4) React DOM은 HTML 어트리뷰트 이름 대신 camelCase 프로퍼티 명명 규칙을
       사용함 
        - JSX 스타일링 
            - JSX에서 자바스크립트 문법을 쓰려면 { }를 써야하기 때문에
              스타일 적용할 때에도 객체 형태로 넣어 주어야 함.
              - 카멜 표기법으로 작성해야 함
                - 예) font-size => fontSize  

    5) class 대신 className
        - JSX에서는 class가 아닌 className을 사용함    

    6) 중요한 데이터는 변수가 아니고 state에 저장함 
        - state에 데이터를 저장해서 쓰는 이유
            - state는 변동사항이 생기면 state쓰는 html도 자동으로 재렌더링함
