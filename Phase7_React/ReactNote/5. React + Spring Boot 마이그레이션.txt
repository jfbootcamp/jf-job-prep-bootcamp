2. Origin 
    1) 정의 
        - 프로토클 + 도메인 + 포트 세 가지를 합친 주소 식별자임
          https:// localhost port
        - 이 세개를 합친 것임 
    2) CORS 
        - Cross-Origin Resouce Sharing
          ------------ -------  -------------
          다른 Origin을   자원(리소스)을   공유하는것
          가로질러(교차해) 
        - 직역하면 "다른 출처 간 자원 공유"
        - 즉 Origin이 다른 곳끼리 데이터를 주고받을 수 있도록 허용하는 메커니즘임.
        - React(:5173) -----> Spring Boot(:8085)의
                                Resouce(JSON 데이터)를 
                              Sharing(공유) 함.
        - 기본은 차단이고, CORS 설정은 "다른 Origin이지만 공유를 허용함"을
          서버에서 명시적으로 선언해야함.
    3) 동일 출처 정책 (Same-Origin Policy)
        - 브라우저에는 Same-Origin Policy가 내장되어 있음
        - 보안상 이유로 다른 Origin으로의 요청은 기본으로 차단함 
        - 이 정책은 서버가 아닌 브라우저가 강제하는 규칙임.
            - Spring Boot쪽에서 "이 Origin 에서 오는 요청은 허용한다"고
              명시적으로 열어줘야 함.
