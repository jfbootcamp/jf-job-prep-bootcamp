1. 훅(Hook) 이란?
    1) 함수형 컴포넌트에서 React의 기능을 연결하는 함수
    2) 이름이 반드시 use로 시작함
    3) React가 훅의 호출 순서로 state를 추적, 관리함.
    4) React 16.8에 도입됨 (2019.02)

2. 훅의 종류
    1) 기본 훅 
        - 대부분의 컴포넌트에서 사용
        - useState
            - 상태 저장
        - useEffect
            - 랜더 후 부수효과 실행  
            - 외부 세계와 상호작용 
        - useContext
        - useRef
    2) 성능 최적화 훅
        - useMemo
        - useCallback
    3) 심화 훅 
        - useReducer 
    4) 커스텀 훅                

3. useState vs useEffect
    1) 비유로 이해하기 
        - useState = 냉장고 
            - 값을 저장하고 꺼내 쓰는 곳
        - useEffect = 마트 심부름  
            - 냉장고를 채우기 위해 밖에 나가는 행동 
        - 냉장고(useState)를 채우려면 누군가 마트(API)에 다녀와야 함
          그 심부름을 랜더가 끝난 후 실행하도록 예약하는 것이 useEffect임. 
    2) 핵심 속성 비교
        속성            useState            useEffect
        ---------------------------------------------------
        역할            값을 읽고 변경          랜더 후 외부 작업
        실행 위치        render 함수 안         render 이후 
        반환값          [값, setter 함수]       없음
        화면 영향       값 변경 --> 즉시 리렌더   직접 없음
        주요 사용처     클릭,입력,토클 상태       fetch,타이머
