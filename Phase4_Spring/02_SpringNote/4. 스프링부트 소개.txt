1. Spring Boot 
    1) Spring Framework을 쉽고 빠르게 사용하기 위한 도구 
        - 개발자가 비즈니스 로직에만 집중할 수 있도록 나머지를 자동해주는 프레임워크 
    2) 자동 설정 (Auto Configuration)
        - 복잡한 XML 설정이 필요 없음!
        - Spring Boot가 알아서 설정해 줌 
    3) 내장 톰캣 (Embedded Tomcat)
        - 웹 서버를 별도로 설치할 필요 없음!
        - Spring Boot 안에 톰켓이 내장 
    4) Starter 의존성 
        - 관련 라이브러리를 묶어서 한번에 추가!
        - spring-boot-starter-web 하나만 추가하면 됨  
    5) 빠른 개발 
        - 최소한의 설정으로 바로 웹 애플리케이션 시작 가능!
        - main() 실행 한번이면 OK
