    1) 서버 IP : 210.xxx.xxx.xxx

3. 전체 흐름

    3) 기존 실행 중인 앱 종료

4. STEP1 -- Intellij에서 JAR 빌드

        - 정보 입력
            - remote host : 210.xxx.xxx.xxx
            - username : onepass

6. STEP3 -- 기존 실행 중인 앱 종료 
    1) 반드시 새 JAR 업로드 전에 기존 프로세스를 종료해야 함.
        - 종료하지 않고 JAR만 바꿔도 현재 실행 중인 앱은 그대로 유지됨 
        - 재시작해야 새 코드가 반영됨 
    2) 현재 실행중인 Java 프로세스 PID 확인 
        - ss : 리눅스에서 현재 열려 있는 네트워크 소켓(포트) 목록을
               보여주는 명령어 
               -t : TCP 소켓만 표시 
               -ㅣ : 현재 LISTEN(대기)중인 포트만 표시 
               -n : 포트 번호를 숫자로 표시 (이름 대신)
               -p : 해당 포트를 사용 중인 프로세스 이름과 PID 함께 표시 
        - | grep 8090 : 결과 중 8090이 포함된 줄만 필터링 

        - ps : 현재 실행 중인 프로세스 목록을 보여주는 명령어임
                -e : 시스템의 모든 프로세스 표시 
                -f : 전체 정보 표시 
        - | grep java : 결과 중 java가 포함된 줄만 필터링  
    3) 앱 정상 종료
        - kill <PID>
            - kill : 특정 프로세스에 종료 신호를 보내는 명령어 
                - 기본 신호 SIGTERM(15): 앱이 현재 처리 중인 요청을 
                                        마무리하고 깔끔하게 종료함 
        - kill 449961    
        - 종료가 안 될 경우 강제 종료
            - kill -9 <PID>
                - -9 : SIGKILL 신호를 보냄 
                       앱에게 정리할 시간을 주지 않고 즉시 강제 종료함 
                - 일반 kill로 종료가 안 될 때(앱이 응답 없는 상태 등)만 사용함.   

7. STEP4 --  MobaXterm FTP로 JAR 파일 업로드 
    1) 왼쪽 패널 로컬 탐색기에서 jar 파일 찾기 
    2) 해당 JAR 파일을 MobaXterm 왼쪽 패널에 드래그 앤 드롭으로 업로드 
    3) 업로드 완료 후 파일 목록에 JAR가 보이면 성공 
        - 기존 파일과 이름이 같으면 자동으로 덮어쓰기 됨                     

8. STEP5 - nohup으로 앱재시작 
    nohup java -jar hometalk-0.2.2-SNAPSHOT.jar > app.log 2>&1 &
    1) nohup 
        - No Hang Up 
        - SSH 터미널을 닫거나 연결이 끊겨도 앱이 계속 실행되도록 함 
    2) > app.log
        - 앱의 표준 출력(System.out)을 app.log 파일에 저장 
       2>&1 
        - 에러 출력(stderr)도 같은 app.log에 함께 저장   
       &
        - 백그라운로 실행  

    3) 실행 확인
        - ss -tlnp | grep 8086
            - 결과 예시
(LISTEN 0      100                *:8086             *:*    users:(("java",pid=734918,fd=14)))        

        - tail -f app.log 
            - tail : 파일의 끝부분을 출력하는 명령어 
            - -f : follow, 파일에 새 내용이 추가될 때마다 실시간으로
                   계속 출력함.  로그를 실시간으로 모니터링 할때 사용함 
            - 종료 하려면 Ctrl + C를 누름.
