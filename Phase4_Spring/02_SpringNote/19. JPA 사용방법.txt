2. 기본 제공 메서드 
    1) JpaRepository가 자동으로 제공 
        - findAll() --> SELECT * FROM book 
        - findById(id) --> SELECT * FROM WHERE id = ?
        - save(entity) --> INSERT / UPDATE 
        - delete(entity) --> DELETE FROM book WHERE id = ? 
        - count() --> SELECT COUNT(*) FROM book 

        - @Query 필요 없음 
        - 메서드 이름만으로 동작 

3. 쿼리 메서드를 사용하는 방법   
    1) Spring Data JPA를 사용하면 간단히 메소드 이름을 선언하여
       저장소 인터페이스에서 쿼리 메서드를 정의할수 있음 
       - 메서드 이름은  Spring Data JPA에 의해 구문 분석되어
         적절한 SQL 쿼리를 생성함 
       - 예
          - userName으로 회원 단건 조회
            - 생성되는 SQL 
                - select * from customers where username = ? 

    2) 메서드 이름 규칙 
        키워드                      메서드 예시                     생성되는 SQL 
      ------------------------------------------------------------------------
       findBy                   findByTitle(String title)
                                findByUsername(String userName) 
                                findByUsernameContaining(부분일치)     WHERE username LIKE '%?%'
       readBy/getBy/queryBy 
       countBy
       existBy
       deleteBy/ removeBy                    



4. JPQL (Java Pesistence Query Language)
    1) 엔티티(클래스) 기준으로 쿼리 작성 
    2) 예
        @Query("SELECT AVG(r.rating) FROM Review r WHERE r.book.id =:book_id")
        public Double findAverageRatingByBookId(@Param("book_id") Long book_id);        
    3) 특징 
        - Review = 엔티티 클래스명 (테이블명 아님)
        - r.book.id = 객체 탐색(r.book_id 아님) 
        - r.rating = 필드명(컬럼명 아님)

        - DB 변경해도 코드 수정 최소화 
        - 실무에서 가장 많이 사용 

5. Native Query (순수 SQL)
    1) 실제 DB 테이블/컬럼 기준으로 쿼리 작성 
    2) 예
        @Query(value="SELECT AVG(r.rating) FROM review r WHERE r.book_id"
                , nativeQuery = true)     
    3) 특징 
        - review = 실제 테이블명 (소문자)                          
        - r.book_id = 실제 컬럼명 (스네이크)
        - nativeQuery = true 필수!

        - DB 종류 바뀌면 쿼리도 수정 필요 
        - DB에 종속적 

6. @Query 코드 완전 분해 

    @Query("SELECT AVG(r.rating) FROM Review r WHERE r.book.id =:book_id")
    public Double findAverageRatingByBookId(@Param("book_id") Long book_id);

    - @Query("...")
        - 역할 : Spring Data JPA에서 "기본 메서드 대신 이 쿼리를 실행해"라고 지시 
        - 위치 : Repository 인터페이스의 메서드 위에 붙임
    - SELECT AVG(r.rating)
        - SELECT : 조회 
        - AVG() : SQL 집계 함수 -- 평균값 계산
        - r.rating: 별칭 r의 rating 필드 --> Review 엔티티의 rating 변수 
        - 결과 : 해당 책의 모든 리뷰 평점 평균 (예: 4.5)      
    - FROM Review r
        - 조회 대상 = Review 엔티티 클래스 (테이블명 아님!)
        - r : 별칭(alias) -- SQL의 "AS r"과 동일 
        - JPQL에서는 반드시 대문자로 시작하는 엔티티 클래스명을 써야 함.
    - WHERE r.book.id =:book_id"
        - 조건절 (어떤 데이터만 가져올지)
        - r.book.id
            - 핵심! 객체 그래프 탐색 
        - r --> Review 엔티티 (별칭)
        - r.book --> Review 클래스의 private Book book; 필드 
        - r.book.id --> 그 Book 객체의 private Long id; 필드 
            
            --> JPA가 내부적으로 review.book_id = ? 로 변환 
    - :book_id <-- 네임드 파라미터 (실행 시 실제 값으로 치환됨)
        - @Param("book_id")과 이름이 정확히 일치해야 함. 

7. JPA 4가지 기능(방법) 비교 

    구분                    ①JpaRepository 기본 메서드          ②쿼리 메서드              ③@Query JPQL             ④@Query Native SQL    
   -------------------------------------------------------------------------------------------------------------------------------------
    선언 방식               상속만으로 사용 (선언 불필요)      메서드명 명명 규칙        JPQL 직접 작성              SQL 직접 작성 
    기준                    Entity                          Entity 필드명           Entity 클래스/필드명         테이블/컬럼명
    설정                      없음                              없음                   기본값(생략 가능)            nativeQuery = true 
    단순 CRUD                  O                                 O                           O                          O 
    복합 조건(AND/OR)           X                                 O(메서드명으로)               O                          O 
    JOIN                       X                                 제한적                       O                          O
    GROUP BY / 집계             X                                 X                           O                          O
    LIMIT                      X                                 X                           X                          O
    DB 전용 함수                X                                 X                           X                          O
    DB 독립성                   O                                 O                           O                          X (DB 종속)
    코드 가독성                 높음                          조건 많으면 메서드명 길어짐          중간                      SQL 그대로라 직관적

8. JPQL @Query (Entity 기준)
    1) 개념 
        Java 코드 (Entity 클래스명/필드명)
                    |
                    |
                   \|/
                @Query(JPQL)
                    |
                   \|/
                JPA가 SQL로 변환
                    |
                   \|/
                   DB 실행
    2) 핵심 규칙 
        항목            JPQL            Native SQL 
      ---------------------------------------------
        대상          Entity 클래스명     테이블명 
        필드          Java 필드명         DB 컬럼명 
        예시          FROM Customer c    FROM customers 
        예시          c.customerName     customer_name  
        파라미터       :param + @Param      ?1, ?2
