2. 파일 업로드 방식 
    1) 데이터 타입 불일치 
        - JSON = 텍스트(문자열) 기반 데이터 포맷
        - 파일 = 바이너리(binary) 데이터 
                0과 1로 이루어진 바이트 덩어리 
                문자열로 표현할 수 없는 바이트가 포함됨 
    2) Base64 인코딩
        - Base64 문자열로 변환하면 JSON에 담을 수 있음
        - 실무에서 거의 사용 안함
            - 파일 크기가 약 33% 증가
            - 서버에서 Base64 디코딩 작업 추가 필요 
            - 메모리 부담 
                - 대용량 파일을 문자열로 통째로 올리면 브라우저 메모리 급증  
    3) FormData 방식으로 파일 전송
        - 단일 파일
            - formData.append('files', file)
        - 다중 파일
            - 배열을 만들어  여러 번 append함
