1. Model 
    1) Controller에서 View(JSP)로 데이터를 전달하는 가방 

    2) 문자열 전달 (index 메서드)
        - Controller에서
            - model.addAttribute("hello", "Hello JSP, Mybatis");
        - Model 가방 안 
            - key="hello"
            - value ="Hello JSP, MyBatis"
        - JSP 에서 
            - ${hello} 

    3) DB에서 조회한 리스트 전달 (bookLists 메서드)
        - Controller에서
            - List<Book> list = bookService.bookList();
            - model.addAttribute("list", list);                   
        - Model 가방 안 
            - key="list"
            - value =List<Book>    
        - JSP 에서
            - <c:forEach var="book" items="${list }">  
            - 리스트 반복 출력 

    4) @PathVariable로 단건 조회 (bookView 메서드)
        - URL 요청 : /bookView/3
        - @PathVariable Long id
            --> id = 3 
        - Book book = bookService.getBook(id);
          model.addAttribute("book", book);

    5) 폼 데이터 자동 바인딩 (bookUpdate POST)  
        - HTML Form 
            <input name="title" value="자바25">                                                  
            <input name="price" value="30000">  
            <input name="author" value="이순신">  
        - Spring 데이터 바인딩 
            (hidden id 포함)
            name="title" --> book.setTitle("자바");
            name="price" --> book.setPrice(30000);    
            name="author" --> book.setAuthor("이순신");
        - Controller 파라미터 
            bookUpdate(Book book)
            --> book 객체에 자동으로 값이 채워짐!
