1. SSR (Thymeleaf)

    브라우저 
    ---------
    GET /web/ 요청 -------------->  Spring Boot 서버 
                                   ------------------ 
                                   Controller + Thymeleaf
                                   HTML을 완성해서 전송
     브라우저       <---------------
    ------------
    HTML 그대로 표시 (JS 불필요)           

2. CSR (React)       
    브라우저 
    ---------
    빈 HTML + JS 다운로드 --------------> Spring Boot 서버 
                                   ------------------ 
                                   REST API만 제공
                                   JSON 데이터만 전송
     브라우저       <---------------
    ------------
    JS로 HTML을 직접 생성
     (화면 담당) 

3. Thymeleaf 문법 핵심 
    1) 텍스트 출력 
        th:text 
            - 태그 안의 텍스트를 변수 값으로 교체
    2) URL 링크
        th:href 
            - 링크 주소를 동적으로 생성 
    3) 반복 
        th:each 
            - 리스트를 순회하여 태그를 반복 
    4) 조건부 랜더링 
        th:if / th:unless
            - 조건에 따라 표시/숨김 
    5) Fragment (컴포넌트)  
        th:fragment + th:replace 
            - 재사용 가능한 HTML 조각 정의 & 호출   

4. Expression(표현식) 종류
    1) ${...}   
        - 변수 표현식 
    2) @{...}
        - URL 표현식 
    3) ~{...}
        - fragment 표현식 
        - 다른 파일의 fragment를 가져올 때         

5. Fragment 란
    1) 재사용 컴포넌트
    2) 반복되는 HTML 조각을 한 번만 정의하고 여러 곳에서 재사용하는 기능임                                                    
    3) 파라미터를 전달 할 수 있어서 같은 구조, 다른 데이터로 렌더링을 할 수 있음 
    4) STEP 1
        - Fragment 정의 (별도 파일)
       STEP 2
        - Fragment 호출 (사용하는 파일)       
    
    5)  ~{...} 표현식 분해 
        
            ~{파일경로 :: fragment이름(파라미터)}
                - 파일경로 
                    - templates 기준 상대 경로 (.html 생략)
                - fragment이름
                    - th:fragment에서 정의한 이름 
                - 파라미터
                    - 전달할 데이터 (여러 개 가능, 쉼표로 구분)
