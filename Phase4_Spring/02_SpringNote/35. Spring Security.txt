1. Spring Security 란?
    1) Spring 기반 애플리케이션에 인증(Authentication)과 인가(Authorization) 기능을
       제공하는 프레임워크임
       -    용어                        의미                        예
         -------------------------------------------------------------------------------------
         인증(Authentication)      이 사람이 누구인가?              로그인 = 신원 확인 
         인가(Authorization)       이 사람이 무엇을 할 수 있는가?    ADMIN만 관리자 페이지 접근 가능
       
       - 인증 없이는 인가도 없음. 
            - 먼저 "누구인지" 확인하고, 그 다음 "무엇을 할 수 있는지" 판단함 


    2) build.gradle에 의존성을 추가하는 순간 
       모든 요청을 대해 인증을 요구하는 상태로 자동 활성화됨     
        - SecurityFilterChain 구성을 커스터마이징해야 함      

2. 적용 전과 적용 후
    1) 적용 전 (직접 구현)
        - 매 컨트롤러마다 직접 검사
        - 예
            @GetMapping("/admin")
            public String admin(HttpSession session) {
                if (session.getAttribute("user") == null) {
                    return "redirect:/login";       // 인증 체크를 개발자가 직접
                }                    
                if ("ADMIN".equals(session.getAttribute("role"))) {
                    return "redirect:/403";         // 인가 체크도 직접
                }
                return "admin";
            }
        
        - 코드 중복 --> 컨트롤러마다 반복
        - 체크를 빠뜨리면 보안에 취약점 발생됨 
        - 세션 관리 취약점 

    2) 적용 후 (Spring Security)
        - SecurityConfig에 한 번만 선언
            .requestMatchers("/admin/**").hasRole("ADMIN") 

            - 인증/인가 로직을 한 곳에서 관리 
            - BCrypt 암호화, 세션 관리 자동 제공
            - 필터 체인 방식으로 요청을 가로채 처리     

        - 컨트롤러는 자기의 본연의 역할에만 집중
            @GetMapping("/admin")
            public String admin(Model model) {
               model.addAttribute("members", memberService.findAll());
               return "admin"; 
            }
