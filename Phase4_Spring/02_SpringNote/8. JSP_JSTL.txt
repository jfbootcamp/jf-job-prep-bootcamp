1. JSP (JavaServer Pages)
    1) HTML 코드 안에 Java 코드를 넣을 수 있는 파일 
    2) 서버에서 실행되어 최종 HTML을 만들어 브라우저에 전송 
    3) 브라우저가 /bookList 요청 
        --> Controller가 데이터를 Model에 담음 
        --> bookList.jsp 파일이 서버에서 실행됨 
        --> JSP안의 JSTL 코드가 동작하여 HTML 생성 
        --> 완성된 순수 HTML이 브라우저로 전송!
    4) 브라우저는 JSP를 모름! 순수 HTML만 받음!
        - JSP는 서버 사이드 랜더링 (SSR)
            - 서버에서 HTML을 만듦 

        - 참고
            - SSR (Server Side Rendering)
                - 서버에서 HTML을 만들어 전송
                - 기술 : JSP, Thymeleaf, php 등
                - 장점 : SEO 유리, 초기 로딩 빠름 
                - 단점 : 페이지 이동마다 서버 요청 
            - CSR (Clinet Side Rendering)          
                - 브라우저(클라이언트)에서 HTML 생성
                - 기술 : React, Vue, Angular 등
                - 장점 : 빠른 화면 전환, SPA 가능
                - 단점 : 초기 로딩 느림, SEO 어려움     

2. JSP 파일의 구성 요소 
    1) 페이지 지시어 (Page Directive)
        - <%@ page contentType="text/html;charset=UTF-8" language="java" %> 
        - 이 jsp 파일의 인코딩과 언어 설정 

    2) 태그 라이브러리 선언 (Taglib)
        - <%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
            - JSTL 코어 태그 사용 (c: 접두사)  
        - <%@ taglib prefix="fmt" uri="http://java.sun.com/jsp/jstl/fmt" %>  
            - JSTL 포맷 태그 사용 (fmt: 접두사)

    3) EL(Expression Language) 표현식 
        - ${hello}
            - Model에서 "hello" 키의 값을 출력 
        - ${book.title}
            - book 객체의 title 필드값 출력 (getter 호출)    

    4) Context Path 변수 설정
        - <c:set var="contextPath"  value="${pageContext.request.contextPath}"/>
            - /mybatis를 contextPath 변수에 저장 
            - 링크에서 ${contextPath}/bookList 처럼 재사용 

3. jsp:include
    1) 공통 컴포넌트 분리와 재사용 
        - 공통 부분을 별도 JSP로 분리하고 include
        - 하나만 수정하면 모든 페이지에 반영 
        - 예)
                                        index.jsp               bookList.jsp           (미래 페이지)
        navbar.jsp                     ----------               --------------
        (공통 상단 내비게이션)            include navbar.jsp         include navbar.jsp
                                        [메인 콘텐츠]                [도서 목록 테이블] 
        foot.jsp                       include footer.jsp         include footer.jsp
        (공통 하단 푸터)


4. JSTL (JSP Standard Tag Library) 핵심 태그 
    1) c:forEach - 반복문 (가장 많이 사용)
            <c:forEach var="book" items="${list }">
                ${book.id}  / ${book.title}  / ${book.price}
            </c:forEach>      

                - items="${list }   ---> Model의 list를 가져옴  
                - var="book" --> 하나씩 꺼내서 book 변수에 담음 
                - Java 대응 
                    - for(Book book : list) 

    2) c:if - 조건문 
    3) c:set - 변수 설정 

    4) fmt:formatDate - 날짜 포맷팅
