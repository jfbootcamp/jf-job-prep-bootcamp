1. 레거시 프로젝트 
    1) 현업에서 레거시를 만나는 건 현실임 
    2) 현업의 현실
        - 공공기관 / 대기업 
            - 10~20년 된 시스템이 지금도 운영 중 
            - 전자정부프레임워크 
                - Spring 2.x ~ 3.x 기반 
        - 금융권 / 보험 
            - 안정성이 최우선
            - 잘 실행되는 시스템을 굳이 바꾸지 않음
            - JSP + Spring MVC + iBatis
        - SI / 외주 프로젝트
            - 납품 후 유지보수 계속 
            - 새 기술로 전환 혹은 전환 할 예산이 없을수 도 있음 
            - Servlet + JSP 그대로 운영  / Spring Boot 
        - 스타트업 (초기)
            - 빠르게 만든 코드가 성장하면서 레거시가 됨 
            - Spring Boot
