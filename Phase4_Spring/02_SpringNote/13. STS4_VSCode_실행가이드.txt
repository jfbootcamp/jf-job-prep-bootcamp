4. Java 컴파일러 옵션 설정
    - '-parameters' flag를 추가 
        - Spring Boot 4.0 (Spring Framework 7)부터 @PathVariable, @RequestParam 등의
          파라미터 이름을 리플렉션으로 자동 감지하는 기능이 제거됨
        - 이 플래그를 추가하면 컴파일 시 파라미터 이름 정보가 바이트코드(.class)에 
          포함되어 Spring이 파라미터 이름을 정상적으로 인식할 수 있게 됨
        - @PathVariable Long id 처럼 이름을 명시하지 않아도
          Spring이 알아서 매핑해줌 
    - Spring 7에서 왜 자동 감지를 제거했나?
        - 성능 문제 
            - 리플렉션으로 파라미터 이름을 읽는 것은 런타임 비용이 큼 
              컴파일 타임에 미리 바이트코드에 포함시키는 것이 훨씬 효율적임
        - 불안정성 문제 
        - 명시적 설정 강제 
            - "마법처럼 알아서 되는 것보다, 명확하게 설정한 것만 동작하게 함"
            - 개발자가 의도를 명확히 하고 예측 가능한 동작 보장하도록 함 
                - 즉, 이 플래그를 추가함으러써 개발자가 
                  "나는 파라미터 이름 감지를 원한다"는 의사를 명확히 표현하게 됨.
