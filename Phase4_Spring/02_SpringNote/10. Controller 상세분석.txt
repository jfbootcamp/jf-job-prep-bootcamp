1. @Controller (웹 요청을 처리하는 클래스)


                        @Controller                             @RestController
                      뷰(JSP) 이름을 리턴                        데이터 (JSON)를 직접 리턴
                      --> 화면을 보여줌                             --> API 서버용 

                      return "bookList"                          return bookList
                      --> bookList.jsp 랜더링                   --> JSON [{id: 1, title: "자바.."}]

                                                                 나중에 REST API에서 사용    

2. @RequiredArgsConstructor  (Lombok)
    1) final 필드에 대한 생성자를 자동 생성 --> 의존성 주입에 사용 

3. Spring Boot가 시작될 때 일어나는 일
    1) @Controller가 붙은 클래스를 찾음 (컨포넌트 스캔)
    2) @RequiredArgsConstructor로 생성자 주입 ---> BookService 연결
    3) Spring 컨테이너에 Bean(객체)으로 등록 
    4) URL 요청이 오면 해당 객체의 메서드를 자동으로 호출 

4. CRUD URL 매핑 - @GetMapping & @PostMapping 
    1) GET 요청 - 조회 / 페이지 이동 

            GET /             ---->    @GetMapping("/") --> index                   홈 페이지 
        GET /bookList         ---->    @GetMapping("/bookList") --> bookList        목록(하드코딩)
        GET /bookLists        ---->    @GetMapping("/bookLists") --> bookList       목록(DB 조회) 
        GET /bookView/{id}    ---->    @GetMapping("/bookView/{id}) --> bookView    상세 조회
        GET /bookUpdate/{id}  ---->    @GetMapping("/bookUpdate/{id}) --> bookUpdateForm   수정 폼 
        GET /bookCreate       ---->    @GetMapping("/bookCreate) --> bookCreateForm        등록 폼

    2) POST 요청 - 데이터 변경 (등록/수정/삭제)

        POST /bookCreate      ---->    @PostMapping("/bookCreate")                  등록 처리 --> redirect
        POST /bookUpdate      ---->    @PostMapping("/bookUpdate")                  수정 처리 --> redirect 
        POST /bookDelete/{id} ---->    @PostMapping("/bookDelete/{id}")             삭제 처리 --> redirect  

5. GET vs POST 정리 

             @GetMapping                                    @PostMapping                            {id} = @PathVariable
         데이터 조회, 페이지/폼 표시                      데이터 변경 (등록/수정/삭제)                       URL에서 값을 추출
            ---> JSP 이름 리턴                            --->  redirect:/bookLists 리턴                 /bookView/3 ---> id=3
