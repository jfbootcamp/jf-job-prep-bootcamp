1. 브라우저가 요청을 보내면 서버는 어떻게 처리하는가?

    1) 1세대 Servlet

            브라우저  -------->    Servlet        --------------------> DB     문제: 하나의 파일이 모든 걸 담당 --> 유지보수 불가능 
            (요청)                - 요청 처리  
                                  - 비즈니스 로직 + DB 접근
                                  - HTML 생성 

    2) 2세대 JSP                                   

            브라우저  -------->    JSP             --------------------> DB      개선: HTML 작성은 편해짐 / 문제 : 여전히 로직+화면 혼합      
            (요청)                - HTML 안에 Java 로직 삽입 + DB 접근 

    3) 3세대 Spring MVC 

            브라우저  --------> Dispatcher -------> Controller -----> Service   -------> DAO   ----------> DB 
            (요청)               Servlet            (요청처리)      (비즈니스 로직)        (DB 접근) 
                                                        |
                                                       \|/                                              역할 분리 완성! / 하지만 XML 설정 파일이 너무 많음 (설정 지옥)
                                                       JSP 
                                                   (화면만 담당) 
    4) 4세대 Spring Boot 

            브라우저    --------> Spring Boot   -------> Controller  -----> Service ------>  Mapper   -----> DB 
            (요청)           (내장 톰켓 + 자동 설정)                                          (MyBatis)
                                                                                               or
                                                                                            Repository
                                                                                            (JPA)        구조는 3세대와 동일! 설정만 자동화됨 ---> 어노테이션 + application.yaml
