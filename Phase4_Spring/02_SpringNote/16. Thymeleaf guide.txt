1. Thymeleaf(타임리프) 란?
    1) Spring Boot 공식 권장 템플릿 엔진 
        - spring-boot-starter-thymeleaf 의존성 하나로 자동 설정 완료
    2) Natural Template
        - .html 파일 그대로 브라우저에서 열어도 디자인 확인 가능 (JSP는 불가)
    3) Java 기반 서버 사이드 템플릿 엔진 
        - Controller에서 Model에 담은 데이터를 HTML에서 동적으로 렌더링 
    4) 확장자
        - .html (표준 html 확장자 사용)
    5) 위치 
        - src/main/resources/templates (Spring Boot Convention)

2. th: 속성 가이드 
    1) 자주 쓰는 th: 속성 

      속성                   용도                    예    
     --------------------------------------------------------------------------------------------------
      th:href       링크 URL 동적 생성 
      th:object     객체 바인딩 (폼/상세)    <form th:object="${member}"> --> 내부에서 *{username} 사용 가능
      th:text       텍스트 출력
      th:action     폼 전송 url    
      th:field      폼 필드 양방향 바인드 
      th:if / th:unless   조건부 랜더링 
      th:classappend      조건부 CSS 클래스 추가   <tr th:classappend="${stat.odd} ? 'bg-gray' ">   --> 기존 class에 조건부로 클래스 추가 (홀수행이면 bg-gray)

    2) 표현식 (Expression)
        - ${...}            변수 표현식 
        - @{...}            URL 표현식 
            - context-path 자동 포함 URL 
        - *{...}            선택 변수 표현식 
            - th:object로 지정한 객체의 필드 
               *{username} = ${username}             

3. Thymeleaf 유틸리티 객체 (Thymeleaf Utility Objects)
    1) 개념
        - 표현식(${...}) 안에서 사용 할 수 있는 내장 헬퍼 객체 
        - Java의 유틸리티 클래스 (Math, String, Collection 등)와 비슷한 역할을 
          HTML 템플릿에서 직접 수행할 수 있게 해줌.

    2) 핵심 특징 
        - #으로 시작 --> ${#객체명.메서드()} 형태로 호출 
        - 별도 import나 Bean 등록 불필요 --> Thymeleaf가 자동으로 제공 
        - View(HTML)에서 간단한 데이터 가공에 사용 (포맷팅, 변환 등)
        - 자바 코드 없이 HTML 만으로 표현 가능 

    3) 유틸리티 객체 목록
           객체명             역할                         대표 메서드                                      Java 대응 클래스     
        - #lists       리스트 검사 (비어있는지, 크기)    isEmpty(), size(), contains(), sort()                  Collections, List   
        - #numbers     숫자 포맷팅 (콤마, 소수점, %)    formatInteger(), formatDecimal(), formatPercent()       DecimalFormat          
        - #temporals   날짜/시간 포맷팅                format(), day(), month(), year()                        DateTimeFormatter

4.  반복문 , 조건문 
    1) th:each 
    2) th:if / th:unless
       th:switch / th:case  
    3) 상태변수(iterStat) 속성들
        - index              0부터 시작하는 인덱스 
        - count              1부터 시작하는 순번 
        - size               전체 요소 수
        - even / odd         짝수/홀수 여부 (boolean)
        - first / last       첫 번째/마지막 여부
