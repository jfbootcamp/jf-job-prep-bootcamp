1. 이미지 업로드 (POST)
    1) POST  /books/{bookId}/images?type=1|2|3
           Content-Type: multipart/form-data

    2) BookController.uploadImages()  
        - @RequestPart 
            - multipart/form-data 요청에서 파일 파트를 꺼내 Java 객체로 바인딩  
        - @PathVariable
            - URL 경로의 {bookId} 부분을 메서드 파라미터로 바인딩 
        - @RequestParam
            - URL 쿼리 파라미터(?type=1)를 메서드 파라미터로 바인딩     
        - 파일별 독립 처리, 일부 실패해도 계속 진행   

    3) BookImageService.saveImage()    @Transactional 
        - ① 빈 파일(isEmpty) 체크 
        - ② MIME 타입 검증 -- image/png, jpg, jpeg 만 허용 
        - ③ 파일 크기 검증 (최대 5MB)
        - ④ 도서당 이미지 수 제한 (최대 10장)
        - ⑤ 안전한 파일명 생성 - RandomStringUtils 10자리 + 확장자만 추출
        - ⑥ 도서별 디렉토리 생성 + 절대 경로 반환 (ImageUtil.makePath()) 
        - ⑦ type=1 --> Scalr 300px 리사이즈 + ImageIO.write() 저장 
            type=2, 3 --> Files.copy() 원본 그대로 저장 
        - ⑧ DB 저장 -- BookImageRepository.save()  
            DB 저장 실패 시 Files.deleteIfExists() --> 디스크 롤백(고아 파일 방지)       

    4) 200 OK  
        - 파일별 성공/실패 분리 -- 일부 실패해도 전체 중단 없음             

2. 이미지 다운로드 (GET - 서빙)
    1) GET /books/{image_id}/imageSrc 
        -> Text 형태로 브라우저 호출 

    2) BookImageController.getImage() 
        - @GetMapping  /{image_id}/imageSrc                                    
            --> 서브스에 DB조회, 파일읽기, MediaType 결정 위임

    3) BookImageService.getImageResource() 
        - ① BookImageRepository.findById()
            없으면 BookImageNotFoundException --> 404
        - ② ImagUtil.getFileAsResource()
            - 파일 경로 조회 
        - ③ File.readAllBytes(path)
            - 이미지 바이트 읽기 
            - 없으면 IOException --> GlobalExceptionHandler --> 500 
        - ④ resolveMediaType
            - 확장자 기반 Content-type 결정 
                - png -->IMAGE_PNG
                - JPG -->IMAGE_JPEB
                - gif -->IMAGE_GIF   

3. BookImageResourceDTO
    1) byte[] data + MediaType mediaType 
        - 서비스가 ResponseEntity 직접 생성 않음
        - 컨트롤러 DTO 받아 ResponseEntity로 포장 
    2) 200 OK 
        - Content-type: image/png | image/jpeg | image/gif   

4. 이미지 삭제 (DELETE)     
    1) DELETE   /books/{image_id}/delete 
        - HTTP DELETE 메서드 (REST 표준 준수)

    2) BookImageController.deleteImage()
        - @DeleteMapping, @ResponseBody 
        --> 서비스에 DB 삭제, 디스크 삭제 위임

    3) BookImageService.deleteImage()
        - @Transactional
        - ① BookImageRepository.findById()
            없으면 BookImageNotFoundException --> 404
        - ② Step1: BookImageRepository.delete() -- DB 먼저 삭제                         
            - @Transactional 범위 내 --> 실패 시 자동 롤백 
        - ③ Step2: ImageUtil.deleteImage() -- 디스크 파일 삭제 
            - @Transactional 범위 밖 DB 삭제 후 실행 

    4) 204 No Content
        - body 없음 (REST 표준: DELETE 성공 시 반환활 내용 없음)                  
       404 Not Found 
        - 이미지 미존재 시
