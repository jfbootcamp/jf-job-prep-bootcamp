1. Review
    1) OOP 3대 특징
        - 캡슐화
            - 데이터 보호 + 은닉
            - private, getter/setter
        - 상속
            - 코드 재사용 + 계층 구조 
            - extends, super
        - 다형성
            - 하나의 타입, 여러 형태
            - 오버라이딩, 업캐스팅                         

    2) 추상클래스와 인터페이스 
        - 추상클래스
            - 이 클래스는 직접 객체로 만들 수 없음. 상속해서 구현해야 함.
        - 인터페이스 
            - 이 기능들을 반드시 구현해야 함. 계약임             

2. 추상화 (Abstraction)            
    1) 정의
        - 복잡한 시스템에서 핵심적인 개념만 추출하여 단순화하는 것 
    2) 현실 세계의 자동차
        - 수천 개의 부품
        - 복잡한 엔진 구조 
        - 전기 시스템, 냉각 시스템 등 
        - 무수한 세부 사항 ...
    3) 프로그래밍 모델 
        - 핵심 속성 : speed, brand, fuel
        - 핵심 동작 : start(), accelerate(), stop()
        - --> 필요한 것만 추출!            

3. OOP에서의 추상화 구현 방법
    1) 추상 클래스 (Abstract Class)
        - 부분적 구현 기능 
        - 상태(필드) 보유 가능 
        - 공통 속성과 일부 구현 공유 시 사용         
    2) 인터페이스 (Interface)
        - 순수한 명세, 구현 없음 
        - 상수만 가능
        - 행위(능력) 정의 시 사용     

4. 추상 클래스 (Abstract Class) 정의 
    1) 인스턴스를 직접 생성할 수 없고, 상속을 통해서만 사용되는 클래스 
    2) 특징 
        - 필드 선언 가능 
            - 일반, static 
        - 생성자 정의 가능 
        - 일반 메서드(구현 포함) 가능
        - 추상 메서드(구현 없음) 가능 
        - new로 직접 인스턴스 생성 불가!
            - 반드시 상속해서 사용 
    3) 일반 클래스 vs 추상 클래스 

                     일반 클래스                       추상 클래스
            -----------------------------------------------------------------
                    new로 객체 생성 가능             new로 객체 생성 불가
                    모든 메서드 구현 필수             추상 메서드 구현 생략 가능            
                    상속 선택사항                    반드시 상속해서 사용
                    완전한 클래스                    불완전한 클래스 (설계도)

5. 추상 메서드 (Abstract Method)
    1) 메서드의 시그니처(선언)만 있고, 구현부(body)가 없는 메서드 
    2) 예
        - public abstract double getArea();
