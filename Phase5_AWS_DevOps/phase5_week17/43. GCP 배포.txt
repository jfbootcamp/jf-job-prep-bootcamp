1. GCP 연결 흐름 
    1) 브라우저 
        - http://34.47.115.41:8085/

    2) GCP VM (hometop-server)
       Ubuntu 22.04 / e2-medium 

    3) Spring Boot JAR  
       port:8085 / profile: prod   

    4) MySQL 8.0 (VM 로컬)
       DB: bookjpa     

2. 배포 단계 
    1) GCP 설정 
        - GCP 프로젝트 생성  
        - VM: e2-medium, Ubuntu 22.04, 30GB
        - 외부 고정 IP 예약 
        - 방화벽 TCP:8085 오픈 

    2) Java + MySQL 설치 
        - SSH 접속
        - openjdk-21 설치
        - mysql-server 설치 
            - systemctl enable mysql 

    3) DB + 유저 생성
        - CREATE DATABASE bookjpa
        - CREATE USER hometop@localhost    
          GRANT ALL PRIVIEGES
          FLUSH PRIVIEGES

    4) prod yaml 작성

    5) 빌드 + 업로드 
        - gradlew bat clean bootJar 
        - GCP SSH 파일 업로드
            - JAR + yaml 파일 업로드 

    6) VM에서 실행                                 

3. 2단계: VM SSH 접속 후 Java + MySQL 설치 

4. 3단계: MySQL DB + 유저 생성

5. 4단계: application-prod.yaml 작성

6. 5단계: 로컬에서 JAR 빌드 
    1) 빌드 결과물 : hometop\build\libs\hometop-0.0.1-SNAPSHOT.jar

7. 6단계: VM에 파일 업로드
    1) GCP SSH 브라우저 상단 파일 업로드 버튼으로 두 파일 업로드함 
        - JAR, yaml 
    2) 업로드 후 홈 디렉토리(~/)에 위치함 

8. 7단계: VM SSH에서 실행
    1) mkdir -p ~/apps/hometalk ~/logs
        - 기본 디렉토리 아님. 직접 생성 
    2) mv ~/hometop-0.0.1-SNAPSHOT.jar ~/apps/hometalk/
        - 업로드된 JAR를 앱 디렉토리로 이동    
    3) mv ~/application-prod.yaml ~/apps/hometalk/
        - 운영 설정 파일을 앱 디렉토리로 이동 
    4) cd apps/hometalk/
    5) nohup java \
        -Dserver.profiles.active=prod \
        -Dserver.port=8085 \
        -Dspring.config.location=file:./application-prod.yaml \
        -jar hometop-0.0.1-SNAPSHOT.jar \
        > ~/logs/hometalk.log 2>&1 &

9. 8단계: 실행 확인
    1) 로그 확인
        tail -f ~/logs/hometalk.log     
    2) 로컬 접속 테스트 
        curl http://localhost:8085
    3) 브라우저 접속 
        http://[vm 외부 IP]:8085

10. 9단계: systemd 서비스 등록 (VM 재부팅 자동 복구)
    1)  nohup 방식은 VM 재부팅 시 프로세스가 사라짐
        - systemd에 등록하면 VM이 재시작되어도 Spring Boot가 자동으로 올라옴 
    2) 서비스 파일 생성
    3) 서비스 등록 및 시작
        - 기존 nohup 프로세스 종료
            - pkill -f "hometop-0.0.1-SNAPSHOT.jar"
        - systemd 등록 + 자동 시작 활성화 + 즉시 시작
            - sudo systemctl daemon-reload
            - sudo systemctl enable hometalk
            - sudo systemctl start hometalk                          
        - 상태 확인 
            - sudo systemctl status hometalk 
        - systemd 주요 명령어
            - sudo systemctl start hometalk     #시작
            - sudo systemctl stop hometalk      #종료
            - sudo systemctl restart hometalk   #재시작
            - sudo systemctl status hometalk    #상태 확인
            - sudo journalctl -u hometalk -f    #실시간 로그 (tail -f 대응)
