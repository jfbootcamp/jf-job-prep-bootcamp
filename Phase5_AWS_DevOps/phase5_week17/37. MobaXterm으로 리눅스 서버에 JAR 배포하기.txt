1. 배포 권한
    1) 팀장, 부팀장만 수행함 
        - 나머지 팀원은 숙지하되, 실제 배포 작업은 팀장/부팀장에게 요청하기

2. 서버 접속 정보
    1) 서버 IP : 210.xxx.xxx.xxx
    2) 계정 : onepass
    3) 배포 경로 : /home/onepass/html/
    4) 앱 포트 : 8090
    5) JAR 파일명 : hometalk-1.0.0.jar 

3. 전체 흐름
    1) Intellij에서 JAR 빌드 
    2) MobaXterm SSH 접속 
    3) 기존 실행 중인 앱 종료
    4) MobaXterm FTP로 새 JAR 업로드 
    5) nohup(no hangup)으로 앱 재시작 
    6) 브라우저에서 동작 확인

4. STEP1 -- Intellij에서 JAR 빌드
    1) Intellij 우측 Gradle 패널 열기 
    2) Tasks -> build -> bootJar 더블 클릭  
    3) 빌드 완료 후 JAR 파일 위치 확인
        - 프로젝트루트/build/libs/hometalk-0.0.1-SNAPSHOT.jar

5. STEP2 -- MobaXterm 설치 및  SSH 접속 
    1) MobaXterm 설치 
    2) SSH 세션 생성 
        - 상단 session 클릭 
        - SSH 탭 선택 
        - 정보 입력
            - remote host : 210.xxx.xxx.xxx
            - username : onepass 
            - port : 22

6. STEP3 -- 기존 실행 중인 앱 종료 
    1) 반드시 새 JAR 업로드 전에 기존 프로세스를 종료해야 함.
        - 종료하지 않고 JAR만 바꿔도 현재 실행 중인 앱은 그대로 유지됨 
        - 재시작해야 새 코드가 반영됨 
    2) 현재 실행중인 Java 프로세스 PID 확인 
        - ss : 리눅스에서 현재 열려 있는 네트워크 소켓(포트) 목록을
               보여주는 명령어 
               -t : TCP 소켓만 표시 
               -ㅣ : 현재 LISTEN(대기)중인 포트만 표시 
               -n : 포트 번호를 숫자로 표시 (이름 대신)
               -p : 해당 포트를 사용 중인 프로세스 이름과 PID 함께 표시 
        - | grep 8090 : 결과 중 8090이 포함된 줄만 필터링 

        - ps : 현재 실행 중인 프로세스 목록을 보여주는 명령어임
                -e : 시스템의 모든 프로세스 표시 
                -f : 전체 정보 표시 
        - | grep java : 결과 중 java가 포함된 줄만 필터링  
    3) 앱 정상 종료
        - kill <PID>
            - kill : 특정 프로세스에 종료 신호를 보내는 명령어 
                - 기본 신호 SIGTERM(15): 앱이 현재 처리 중인 요청을 
                                        마무리하고 깔끔하게 종료함 
        - kill 449961    
        - 종료가 안 될 경우 강제 종료
            - kill -9 <PID>
                - -9 : SIGKILL 신호를 보냄 
                       앱에게 정리할 시간을 주지 않고 즉시 강제 종료함 
                - 일반 kill로 종료가 안 될 때(앱이 응답 없는 상태 등)만 사용함.
