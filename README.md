# Java Full-Stack Developer Bootcamp (6 Months)

이 저장소는 24주(960시간) 풀스택 개발자 양성과정의 강의 자료 템플릿입니다.
Phase별로 프론트엔드, 백엔드, 데이터베이스, 스프링, AWS/DevOps, 최종 프로젝트까지 학습할 수 있도록 구성되어 있습니다.

## 📦 Phase 구성
- Phase 1: Frontend 기초 (HTML/CSS/JS) 
- Phase 2: Java Core 
- Phase 3: DB, JDBC, Servlet/JSP 
- Phase 4: Spring Framework & Spring Boot (React)
- Phase 5: GCP & DevOps 
- Phase 6: Final Project & Job Preparation
